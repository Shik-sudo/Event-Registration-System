# Event Registration System (HTML, CSS, JavaScript)

A beginner-friendly and presentable college mini project.

## Features
- Landing page with event cards
- Registration form with JavaScript validation
- Confirmation message after successful submission
- Recent registrations list (saved in browser `localStorage`)
- Responsive design for mobile and desktop

## How to run in VS Code
1. Open this folder in VS Code.
2. Install the **Live Server** extension (optional but recommended).
3. Open `index.html`.
4. Right-click and choose **Open with Live Server**.

You can also directly open `index.html` in any browser.

## Project files
- `index.html` → page structure
- `style.css` → styling and responsive layout
- `script.js` → data, validation, and localStorage logic

## Customization ideas
- Add your own college logo and department name.
- Update event names and dates in `script.js`.
- Add more fields (department, roll number, etc.).
- Connect to a backend later (Node.js / PHP / Firebase) if required.
